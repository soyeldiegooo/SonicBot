This concept sketch shows the initial SonicBot design: a standalone, sampler-driven MIDI device with rechargeable power, a custom synth module, and a compact signal flow from handmade boards to audio output.

---

## Features
- Standalone hardware design
- MIDI and sampler workflow
- Rechargeable power
- Compact audio path
- Open-source concept project
